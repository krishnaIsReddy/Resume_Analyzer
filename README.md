# Resume_Analyzer

This is a small app that helps you improve your resume. It puts any resume into the popular "Jake's Resume" format. 
This is a Gemini AI wrapper which provides changes to your resume, converts them into a PDF with a provided HTML file, and allows you to downlaod the improve resume. 

Note: 
There are still a few issues that need to be fixed with the app as the resumes that are output are not nearly perfect.
